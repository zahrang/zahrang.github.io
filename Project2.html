Bond Pricing & Yield Analysis

Python • Fixed Income • Quantitative Modelling

View code on GitHub →

Overview

This project applies discounted cash flow techniques to price fixed-income securities and analyse how bond values respond to changes in market yields.

Model Setup

The analysis compares two 10-year bonds with face value 100 and annual coupons, priced at a 5% yield:

  • Low Coupon Bond (3%): more sensitive to interest rate changes
  • High Coupon Bond (6%): less sensitive, because more of its value comes from earlier cash flows

Method

  • Calculated bond prices using discounted cash flow models
  • Computed Macaulay duration, modified duration and convexity
  • Compared duration-based price predictions against exact repricing for ±1% yield shifts
  • Visualised relationships between price, yield, and maturity

Key Insight

A 1% rise in yield cuts the 3% bond's price by 7.85%, against 7.17% for the 6% bond. This matches its longer modified duration (8.25 vs 7.52) and confirms that lower-coupon bonds carry more interest-rate risk.

Duration alone is a linear approximation, so it overstates price falls and understates price rises, by about 0.35–0.43 percentage points for a 1% shift. Because the price–yield curve is convex, adding the convexity term cuts that error to under 0.02 percentage points.
