Dissertation

Credit Risk • Machine Learning

This page outlines my dissertation, which I will be working on during my final year of university. The project looks at loan default prediction, comparing a traditional statistical approach with a machine learning one to understand which borrower characteristics matter most, and whether a simpler model can be built without giving up predictive accuracy.

Research Question

What is a parsimonious (minimal, most important) set of predictors for loan default, and does a nonlinear machine learning model (Random Forest) select different or fewer variables than penalised logistic regression, without a meaningful loss in predictive performance?
