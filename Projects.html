Tic-Tac-Toe Game Theory Analysis

A simulation study of how optimal and imperfect strategies affect outcomes in Tic-Tac-Toe.

Python • Game Theory • Simulation • Probability • Statistical Analysis
More details

This project models thousands of Tic-Tac-Toe games under different player skill levels to understand how deviations from optimal play affect win/draw/loss distributions. It demonstrates that while perfect play guarantees a draw, introducing realistic human error shifts outcomes significantly.

Key analysis includes: perfect vs perfect play (theoretical draw equilibrium), perfect vs imperfect strategy dominance, imperfect vs imperfect balance effects, and random baseline behaviour.

Letterboxd Watchlist Streaming Checker

A personalised tool that shows which films on a user's Letterboxd watchlist are available on their streaming subscriptions.

Python • Web Scraping • API Integration
More details

Letterboxd is a popular social platform for film lovers to track and review films. This tool monitors a user's watchlist and shows which of those films are included in their streaming subscriptions, making it easier to decide what to watch.

It scrapes the user's public Letterboxd watchlist and checks real-time streaming availability using Google's "Available On" API. Add-on subscriptions and rental options are filtered out, so only content included with the user's active subscriptions is shown.

Key features include automatic change detection (new/removed films) and terminal visualisation with tables and progress bars.
